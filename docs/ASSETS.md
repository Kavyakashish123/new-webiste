# Asset inventory

The complete published frontend comprises `public/index.html` and `public/workspace.js`.

- All styling is embedded in index.html.
- Wappcart wordmark: styled text with a colored dot.
- Navigation icons: Unicode glyphs.
- Avatars: initials inside CSS shapes.
- Charts and progress bars: CSS and HTML.
- Font stack: Inter, Arial, sans-serif; no external font files are loaded.
- No image, raster logo, SVG, video, CDN, or external CSS library is referenced by the published code.
- workspace.js is the sole external script file, bundled alongside index.html.

No assets are omitted. Other logos created in separate conversations are not part of the published website. Content asset URLs entered by a user are stored as records; this project does not upload, embed or download those assets.
